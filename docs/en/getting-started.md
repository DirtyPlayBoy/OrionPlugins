# Getting started

```bash
pip install -e sdk/python
python cli/orion_plugin.py new hello --author "You" --dir ./hello
python cli/orion_plugin.py test ./hello --call
```

In Orion: **Plugins → Development** → enable developer mode → load the folder.

See [cli.md](cli.md), [manifest.md](manifest.md), [publishing.md](publishing.md).
