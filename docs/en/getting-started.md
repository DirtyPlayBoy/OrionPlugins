# Getting started

1. Install the SDK: `pip install -e sdk/python`
2. Scaffold: `python cli/orion_plugin.py new hello --author "You"`
3. Open Orion → **Plugins → Development**
4. Enable developer mode
5. Paste the folder path → **Load**
6. Ask the assistant to use your tool

See also: [manifest.md](manifest.md), [cli.md](cli.md), [publishing.md](publishing.md).
