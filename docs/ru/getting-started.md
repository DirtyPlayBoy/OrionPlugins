# С чего начать

1. SDK: `pip install -e sdk/python`
2. Scaffold: `python cli/orion_plugin.py new hello --author "Вы"`
3. Orion → **Плагины → Разработка**
4. Включите режим разработчика
5. Укажите путь к папке → **Загрузить**
6. Попросите ассистента вызвать ваш tool

См. также: [manifest.md](manifest.md), [cli.md](cli.md), [publishing.md](publishing.md).
