# Calculator

Официальный пример Orion: безопасный калькулятор для ассистента + страница «Калькулятор».

## Tools

- `plugin__calculator__calculate` — выражение (`12*8`, `480*25%`)
- `plugin__calculator__percent_of` — процент от суммы
- `plugin__calculator__split_bill` — разделить счёт с чаевыми

## Install

В Orion → **Плагины → Каталог → Примеры** → «Установить пример», либо:

```bash
orion-plugin pack .
# GitHub Release + CRM Watchlist / orion-registry
```

После включения плагина в меню появляется раздел **Калькулятор**.
